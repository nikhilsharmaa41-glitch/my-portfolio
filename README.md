# Nikhil Sharma | Portfolio
A personal portfolio website that introduces me, my skills and my projects. I'm a BCA student from Mumbai learning web development, and I built this site to practise HTML, CSS and JavaScript and to show my work online.
**Live site:** https://nikhilsharma-dev.netlify.app
## Features
- Responsive layout that works on phones, tablets and desktops
- Light and dark mode toggle
- Smooth scrolling and scroll animations
- Sections for About, Skills, Journey, Projects and Contact
## Built with
HTML, CSS, JavaScript
## Run it locally
Download the files, keep them in one folder, and open `index.html` in your browser.
